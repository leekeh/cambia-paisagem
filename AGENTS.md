## Adding a tour

You will be asked to add tours to the website. You will receive a Portuguese document detailing the tour. Some information, such as the address at the bottom, can be discarded. When you have received the information about the tour, follow the following steps. Execute each step in order, and do not proceed to the next step until you have completed the current one and received confirmation from the user.

- define the slug and verify it with the user. See if there is already a matching slug in the images directory (src/assets/images/[tour-name]), that will be a hint for the slug. Wait for the user to confirm the slug before proceeding to the next step. If available, use an interactive button so the user can click to confirm the slug.
- based on the content of the tour, determine the relevant images that should be included in the tour. Provide the user with a list of images for each step, and the main image for the hero. If there are no appropriate images, ask the user to provide them. Images should match the topic of the step and should be visually appealing. There should generally not be duplicated images, except for if the step really is the same. Do not interrupt yourself until you have provided the complete list. Ask the user to confirm the images are ready before proceeding to the next step. For pickup/dropoff images, use the lisbon_street image. Present the selected images in a table format, with the following columns: image name, description of the step it corresponds to, and a link to the source or description of the image that should be added. Highlight missing with this emoji: 🙏.
- run the optimization script to optimize the images, making sure to add the new directory to the `DIRECTORIES` array in the script if needed. If filenames are not descriptive, contain numbers or other fluff, rename them to be more concise. Remove the images in the tour directory that are not relevant to the tour. Afterwards, revert the optimization script to its original state.
- create the json file with the relevant information about the tour in src/content/tours/[tour-name].json, following the format of the existing tours (use evora.json as reference). Make sure to include all the necessary fields and to format the content correctly. Make sure to properly translate content, including words like "miradouro". It is urgent that the information is consistent with the original document that was received. If there are any fields that are not yet available, such as the price, leave them empty or with a placeholder value, and communicate this to the user. The default price is 120.
- if not already running, start a development server with `pnpm dev`. This task will run in the background until it is closed, so don't await it. Present the user with the url of the tour (`http://localhost:4321/en/tours/[tour-name]`), asking them to verify that all the information is correct and that the images are displayed properly.
